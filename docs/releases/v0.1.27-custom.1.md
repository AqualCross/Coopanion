# Coopanion v0.1.27-custom.1

**跟上官方 v0.1.27;玩具改以补丁包叠在官方安装上**

[AqualCross/Coopanion](https://github.com/AqualCross/Coopanion) fork 的构建,基线是上游 v0.1.27。
相对官方版多一件玩具:它在桌面上能被踢、被拎起来甩,也能换成你自己的图、起你自己的名字。
从这版起它单独打成补丁,叠在官方 Windows x64 安装上,官方自动更新照常;官方每次升级后,重装对应新版本的补丁。

## 新增

- **玩具的默认名字跟着界面语言走**:没起名字时,中文里它叫「铁盆」,英文里叫 basin,日语里叫 たらい,
  其余语言各有叫法;填过名字就只用你填的。事件里叫它什么,和界面同一个语言。

## 改动

- **玩具按官方新版装扮页重排**:换图、填名字、「用回铁盆」和说明收进装扮页最后一组,和形象、配色同一排法。

## 获取

- 补丁 `Coopanion-Toy-Patch-0.1.27-v1.zip`:Windows x64,叠在官方 0.1.27 上。解压后 `Install.cmd` 安装,
  `Check.cmd` 只检查兼容性,`Uninstall.cmd` 还原成官方文件;`使用说明.txt` 写了检测不到安装目录、文件被改过等情况。
