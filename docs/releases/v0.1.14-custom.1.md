# Coopanion v0.1.14-custom.1

**个人 fork 的自用构建:全屏时自动隐藏桌宠**

这是 [AqualCross/Coopanion](https://github.com/AqualCross/Coopanion) 的 fork 构建,基线是上游
v0.1.13,只多下面这一个功能,还没回推上游。

## 新功能

- **全屏时自动隐藏**:前台窗口铺满桌宠所在那块屏时(游戏、视频全屏),桌宠窗口藏起来;那个窗口
  不再是前台,就用不抢焦点的方式放回来。默认关,在设置窗口高级模式的「桌宠」页「配置」里勾
  「全屏时自动隐藏」。只看前台窗口:最大化窗口只占工作区、不算全屏,点桌面也不算。桌宠菜单里
  的「隐藏」不受影响,藏着的桌宠只有这条规则能自己放回来。只在 Windows 上生效。

## 保留原来那份数据

装的时候在「选择安装位置」页把目录改成原来的 `D:\program\Coopanion`。安装器认不出旧目录
(注册表里那条卸载记录的安装位置是空的),默认会给 `C:\Users\<用户名>\Coopanion`;选错目录就是
一份全新的空数据。选对了目录,`data\` 原样留着——安装器的更新路径只按名字删 Electron 自己的
文件。
