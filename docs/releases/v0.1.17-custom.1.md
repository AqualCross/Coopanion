# Coopanion v0.1.17-custom.1

**全屏时自动隐藏:修掉"从最大化进全屏不藏"**

[AqualCross/Coopanion](https://github.com/AqualCross/Coopanion) fork 的构建,基线是上游 v0.1.17,
相对官方版只多这一条修复(全屏自动隐藏本身已随官方 v0.1.16 发布)。

## 修复

- **从最大化状态进全屏时会漏藏**:上游合并这条功能时加了一层"最大化窗口不算全屏"的判断(为了避免
  任务栏自动隐藏的机器上、最大化窗口铺满整屏被误判)。但 Chromium 从最大化进全屏时不会清掉最大化
  状态,于是真全屏被误排除——取消最大化再按 F11 会藏,先最大化再按 F11 不藏。现在改成"盖满整屏、
  且不是带标题栏的普通窗口":带标题栏的最大化窗口照样不算,而进全屏会把标题栏清掉,两种进入方式
  都能藏。
- **被自动藏过、又手动叫回来之后,规则仍然有效**:托盘图标、托盘菜单、桌宠菜单里的「隐藏」都会把
  "这次是这条规则藏的"这个状态收回。之前它们绕开了它,于是后来真全屏也不再藏。
