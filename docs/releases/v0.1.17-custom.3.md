# Coopanion v0.1.17-custom.3

**地上那件玩具换成你自己的:一张图、一个名字**

[AqualCross/Coopanion](https://github.com/AqualCross/Coopanion) fork 的构建,基线是上游 v0.1.17。
相对官方版多三条:这一版的自定义玩具,上一版的铁盆,和再上一版的全屏自动隐藏修复(见 v0.1.17-custom.1)。

## 新增

- **装扮页可以换玩具**:预览下面多了一块「玩具」,点那只盆的方框就能挑一张图当它,旁边填它的名字
  (最长 12 个字)。图会就地缩到长边 384 像素、存成 PNG 放在本地,换回去时点「用回铁盆」。
- **它按图自己的形状落地**:大小按图的长边算,不用迁就内置铁盆那个横长条;竖长的图就站得高,
  方形图就圆滚滚,踢起来、拎起来甩出去的手感不变。
- **改这些不用重开对话**:换图、改名、收走或放出,都是当场生效。它认识的玩具名字来自你填的那个,
  拼在事件里现说,所以「换个玩具就得重开一轮」这回事没有了。

## 改动

- **铁盆改名叫「玩具」**:习惯页里的开关成了「玩具」和「玩具的响声」,说明里也写清了样子和名字在
  装扮页换。这只是同一个开关换了名字,但存过的设置认不回来——**上一版把盆关掉的人,这版它会重新
  出现在桌面上**,去习惯页再关一次就行。
- **它自己踢飞又砸到自己,不再报给它**:它闲着会自己走过去踢,盆落回来是这条循环的一部分,以前每次
  都要说成「伙伴把玩具砸到了你身上」,既冤枉了人,挂着不管还能积上一大堆。现在只留被砸晕的表演——
  走去某处的路上被砸,照旧会停下脚,并且知道自己是为什么停的。
- **它靠事件认识玩具,不靠背景说明**:原先写在系统提示词里关于盆的那段整段删了,玩法并进了盆停下来
  位置那条 `[环境]` 事件。少一段固定说明,也少一样改了要重开会话才生效的东西。
