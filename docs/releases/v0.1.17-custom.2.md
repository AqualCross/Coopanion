# Coopanion v0.1.17-custom.2

**地上多了一只可以踢、可以拎起来甩的铁盆**

[AqualCross/Coopanion](https://github.com/AqualCross/Coopanion) fork 的构建,基线是上游 v0.1.17。
相对官方版多两条:这一版的铁盆,和上一版的全屏自动隐藏修复(见 v0.1.17-custom.1)。

## 新增

- **铁盆**:桌面上躺着一只盆,可以拎起来甩,也可以让它自己踢。习惯页里两个开关——
  「铁盆」收走或放出整只盆,「铁盆的响声」只管盆自己的 clang、抓握和破空声。默认都开着。
- **它会自己找盆踢**:走路路过就顺脚踢飞;盆歇在手够不着的地方,它闲着一会儿会自己走过去踢。
  把「走动」调到「不乱动」,它就不自己过去了。
- **砸中它改成倒地眩晕**:盆甩过来砸在身上,它不再是吓一跳,而是被砸晕、坐在地上晕一会儿;
  正在走去某处时被砸,会停下脚,并且知道自己是为什么停的。
- **它知道盆在哪**:盆每次停下来,那个位置会作为 `[环境]` 事件告诉它,所以它想踢的时候找得到;
  这一砸也会作为 `[互动]` 事件告诉它。两条都跟着下一批事件送,不会为一只盆单独吵醒它。
- 盆和身体用的是同一套重力,落地会弹一下再滚定,被踢飞时甩得出去也转得起来。
